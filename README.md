# Java REST API + Docker + CI/CD Project

##  Project Overview
This project is a simple Java REST API built using core Java (HttpServer). It demonstrates REST API creation, JSON handling, Docker containerization, and DevOps workflow using GitHub.

---

##  Features
- REST API using Java HttpServer
- JSON response using Gson
- Endpoints:
  - /api/health
  - /api/items
- Maven build system
- Docker containerization
- GitHub version control ready

---

##  Technologies Used
- Java 21
- Maven
- Gson
- Docker
- Git & GitHub
